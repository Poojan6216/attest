# Sprint 1 — The ledger core (pure) | Week 2 | Self-paced | 🔥 MOST IMPORTANT
# Spec: build_spec.md §7 (Core contracts) and §8 PHASE 1. Read agents/ledger_engineer.md before 1.1.
# 🔥 HARD RULE — `src/core` IS PURE: no DOM, no `chrome.*`, no Dexie, no I/O, no `Date.now()`, no `Math.random()`,
#    no model. Every module must import and run in plain Node under Vitest. The `no-restricted-imports` rule from
#    Sprint 0 enforces the imports; a grep test enforces the clock and randomness.
# 🔥 Policy is data. Every threshold, window, weight, and allowlist comes from `policy/default.json`. A number in
#    `src/core` that is not a loop index is a bug.
# Goal: `grade()` and everything around it, proven deterministic, replayable, and honest about what it cannot see.
