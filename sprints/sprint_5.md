# Sprint 5 — Optional intelligence and opt-in telemetry | Week 6 | Self-paced
# Spec: build_spec.md §8 PHASE 5. Read agents/intel_engineer.md and agents/backend_engineer.md before 5.1.
# 🔥 HARD RULE — THE MODEL NEVER GRADES. It proposes a candidate score. `grade()` consumes that score as one capped
#    feature. The monotonicity property test is the machine-checkable form of this rule and must be green before
#    any model code is wired in.
# 🔥 THE MODEL NEVER SEES PAGE TEXT. Allowlisted structured fields only. Test doubles assert the exact input.
# 🔥 TELEMETRY IS OFF BY DEFAULT, NUMBERS ONLY, ONE HOST. The network-intercept allowlist grows from zero to exactly
#    one host, and only when the toggle is on. The secret-seed test now covers the telemetry payload.
# Goal: the two opt-ins, proven harmless to every guarantee, plus the only server in the project.
